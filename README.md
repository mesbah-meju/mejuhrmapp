# Auth UI App

Separate Flutter project with **authentication screens UI only** — no Firebase / backend login.

## Screens included
- Onboarding
- Login
- Signup
- Verify Email
- Forget Password
- Reset Password
- Success Screen

## Run
```bash
cd auth_ui_app
flutter pub get
flutter run
```

Buttons show snackbars or navigate between screens only. No real authentication.
